# General HVAC LLC | Website Redesign Concept

A modern, one-page website concept for General HVAC LLC in Harlingen, Texas, designed by [Faro Digital Studio](https://farodigitalstudio.com).

**[View the live concept](https://farodigitalstudio.com/generalHvacConcept/)**

## Features

- Responsive design with a blue-and-white palette and HVAC imagery
- Residential and commercial service information
- Clear calls to action for phone contact and service requests
- Financing information, common questions, and local business details
- Streamlined navigation and a compact branded footer
- Faro concept ribbon and service request form preview

## Status

Initial concept complete and ready for presentation. Built with Bootstrap and hosted on GitHub Pages, with website files in [`docs/`](./docs/).

## Next Steps

Gather feedback, refine the design and content, and prepare service request functionality for a potential production launch.
