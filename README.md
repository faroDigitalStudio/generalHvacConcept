# General HVAC LLC | Website Redesign Concept

An independent, one-page website redesign concept created by [Faro Digital Studio](https://farodigitalstudio.com) for General HVAC LLC in Harlingen, Texas.

**[View the live concept](https://farodigitalstudio.com/generalHvacConcept/)**

## Project

- **Status:** Independent design concept, not a commissioned or official website
- **Focus:** Responsive design, clearer service information, and straightforward contact options
- **Website files:** [`/docs`](./docs/)

## Deployment

Published with GitHub Pages from the `main` branch and `/docs` folder. Updates to the website deploy when changes are pushed to `main`.
